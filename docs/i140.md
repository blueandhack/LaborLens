# USCIS I-140 statistics

`/i140` shows USCIS's national Form I-140 counts. USCIS publishes no I-140 data by employer,
so the page is not linked to employer profiles.

## Sources

The data comes from three quarterly workbooks on
[Immigration and Citizenship Data](https://www.uscis.gov/tools/reports-and-studies/immigration-and-citizenship-data):

| File | Used for |
|---|---|
| `i140_fyYYYY_qN[_vN].xlsx` | Received, approved, denied and pending by quarter and category (summary sheet). Also the latest quarter's receipts and approvals by beneficiary state and country of birth. |
| `i140_rec_by_class_country_fyYYYY_qN.xlsx` | Each fiscal year's petitions (FY2014 onward) by current status, for all countries and five large ones. |
| `eb_i140_i360_i526_performancedata_fyYYYY_qN.xlsx` | Approved petitions waiting for a visa, by country and preference. |

Quarterly history begins in FY2024. Each earlier fiscal year comes from its full-year Q4 file
(`i140_fy2024_q4.xlsx`, `i140_fy2025_q4_v1.xlsx`), and years before FY2024 are published only
as PDFs.

## Importing

```bash
node scripts/import-i140.js    # find the newest workbooks on the data page, download and import
node scripts/import-i140.js --quarterly a.xlsx [b.xlsx ...] --cohorts c.xlsx --awaiting d.xlsx
```

The CronJob `laborlens-i140-refresh` (`k8s/auto-import.yaml`) runs the first form every Monday
at 4:15 AM Pacific. The parsed snapshot is a single document, `uscis_i140` `latest`, of about
90 KB.

The parser locates rows and columns by their labels and by the category codes in parentheses
(E11, NIW, EW3, and so on), so wording changes between years (for example "Needed Unskilled
Workers") still parse. Quarters USCIS has not reported yet are all zeros in the workbook and
are skipped.
